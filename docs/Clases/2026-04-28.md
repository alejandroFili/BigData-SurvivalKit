# Primera version - vista materializada (version pobre)

Preparacion:

```SQL
DROP
CREATE MATERIALIZAED VIEW
EVENTID
%% no se puede mirar directamente %%
suma_V1 AggregateFunction(sum, UInt32) 
media_V2 AggregateFunction(avg, UInt32)
uniq_V2 AggregateFunction(uniq, UInt32)

ENGINE = AggregatingMergeTree() ORDER BY (EventDate, EventID)
AS SELECT
%% numero valores uniqos etc, por hora %%
toStartOfHour (EventDate) as EventDate,
EventID,
sumState(V1) as suma_v1
avgState(V2) as media_v2
FROM EVENTS
GROUP By EventDate, EventID;
```
