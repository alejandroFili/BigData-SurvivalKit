# OLTP

Modelo de gestión clasico OLTP (procesamiento de...online)
- transaccionales
- es el de gestión de referencia
- objetivo: soportar el procesamiento de datos de las empresas
- principal actor SGBD relacional
- Operacional en su conjunto, muchos gestores cada uno con sus bases de datos

>[!Danger] Cada base de datos es un universo aparte, el gestor relaciona los datos de una base de datos pero no entre diferentes. Problema : como integro todo en algo coerente


# OLAP

Procesamiento Analítico Online.

- Objetivo:
	- soporte al analisis de datos
	- esto si que es Big Data

>[!Danger] OLAP no deberia afectar al OLTP
